# Glide Homebrew tap

```sh
brew tap glideidentity/glide https://github.com/GlideIdentity/glide-homebrew-tap
brew install --cask glideidentity/glide/glide
```

`Casks/glide.rb` is generated by GoReleaser on each release of the Glide CLI. Do not edit it by hand; changes are overwritten on the next release.
